# US Options Tracker — 美股大额未平仓期权追踪看板

基于 Nasdaq 免费公开数据的自包含期权追踪看板：追踪自选标的大额未平仓合约（Open Interest），全市场扫描，并自动筛选出**异常度 TOP 5** 的期权合约。

## 功能

- **自选池视图**：追踪自选标的的未平仓合约，按 OI / 成交量排序浏览
- **全市场扫描**：30 个标的的全量期权链扫描
- **异常 TOP 5**：按综合异常度评分自动筛选最值得关注的 5 个合约
- **每日自动更新**：本地服务启动时自动抓取最新数据，后台每 30 分钟巡检，发现新交易日数据自动更新（60 分钟冷却窗口防循环重抓）

## 异常度评分

异常判定硬门槛：**期权价格偏离标的现价 ≥ 50%**（可调，10%~200% 滑块）。满足门槛后按以下权重综合评分（0~100 分）：

| 维度 | 权重 | 说明 |
|---|---|---|
| 价格偏离度 | 40% | 期权价格相对标的现价的偏离，偏离越大权重越高 |
| 资金占比 | 25% | 该合约 OI 名义金额占标的全部合约 OI 名义金额的比例 |
| 成交量/OI 比 | 20% | 当日换手活跃度（含绝对下限校验，避免低活跃合约误标） |
| 未平仓量 | 10% | OI 绝对规模 |
| 剩余天数 | 5% | 临近到期加分 |

## 快速开始

```bash
# 依赖：Python 3.8+（无需第三方库，仅标准库）
python serve.py
```

服务默认运行在 `http://127.0.0.1:8787`，启动时自动抓取最新数据并打开浏览器。

```
用法: serve.py [--port 8787] [--no-open] [--no-fetch] [--force]
             [--check-every 30] [--retry-after 60]
```

独立窗口启动（Windows）：双击 `start_dashboard.bat`。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 自包含看板页面（原生 JS + ECharts，离线加载 `options_data.js`） |
| `fetch_options.py` | 数据抓取器：Nasdaq 期权链 API → 紧凑列式 JS 数据文件 |
| `serve.py` | 本地 HTTP 服务 + 定时自动更新（`/api/status`、`POST /api/refresh`） |
| `options_data.js` | 数据文件（随抓取每日更新，可直接用浏览器打开 index.html 离线查看） |
| `start_dashboard.bat` | Windows 一键启动脚本 |

## 数据说明

- 数据源：`api.nasdaq.com` 期权链接口（免费、无 Key）
- OI（未平仓量）为日终结算指标，T+1 才有，故数据日 = 最近已收盘交易日
- 数据文件含 `asOf`（数据日）、`marketPhase`（抓取时段市场状态）、`oiState`（数据日判定）等元信息，前端据此标注「持仓结算日」等状态，避免误读盘中跳动的标的报价
